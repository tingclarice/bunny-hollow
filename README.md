# Quoridor

Starter project for a Human-vs-AI Quoridor game built with Python and Pygame.

## Bootstrap

Run the folder setup script from the project root:

```bash
bash setup_project.sh
```

Install the listed dependencies with:

```bash
python -m pip install -r requirements.txt
```

Run the application with:

```bash
python main.py
```

The engine and AI files currently define API skeletons only; game rules,
search, pathfinding, and rendering are not implemented yet.
